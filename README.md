# ExpenseBot

Учёт расходов: библиотека `expensebot`, консольная утилита и документация API.

## Запуск
```bash
python -m expensebot add 350.5 Еда -c "Обед"
python -m expensebot list
python -m expensebot report
python -m pytest
```
