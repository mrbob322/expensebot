# Глоссарий

| Термин | Определение |
|---|---|
| Бот | Программа, которая получает сообщения пользователей в Telegram и отвечает на них автоматически. |
| Telegram Bot API | HTTP-интерфейс Telegram для создания ботов и обмена сообщениями с пользователями. |
| Токен бота | Секретная строка, выданная BotFather, по которой Telegram определяет, какому боту принадлежат запросы. |
| User (пользователь) | Человек, который общается с ботом; идентифицируется числовым `user_id` Telegram. |
| Расход (Expense) | Запись о потраченной сумме с категорией, комментарием и датой. |
| Категория | Слово, обозначающее тип траты (например, «еда», «транспорт»); хранится в нижнем регистре. |
| Комментарий | Необязательный текст после категории, поясняющий расход. |
| Команда | Сообщение, начинающееся с «/» (`/start`, `/report`), которое запускает заранее заданное действие бота. |
| Отчёт | Сводка расходов пользователя по категориям за период (по умолчанию — текущий месяц). |
| Парсер | Модуль, который превращает текст сообщения в структурированные данные (сумма, категория, комментарий). |
| Репозиторий (Repository) | Класс, скрывающий детали работы с базой данных и предоставляющий методы «сохранить» и «получить». |
| Сервис (Service) | Слой бизнес-логики между обработчиками Telegram и репозиторием. |
| ADR | Architecture Decision Record — документ, фиксирующий архитектурное решение и его обоснование. |
| MVP | Minimum Viable Product — минимальная версия продукта, достаточная для проверки идеи на пользователях. |
| MoSCoW | Метод приоритизации требований: Must, Should, Could, Won't. |
| Копейка (minor unit) | Наименьшая единица валюты; суммы хранятся в копейках как целые числа, чтобы избежать ошибок округления. |
| SQLite | Встраиваемая реляционная СУБД, хранящая базу в одном файле. |
| Линтер | Инструмент, который находит в коде нарушения стиля и потенциальные ошибки (flake8). |
| Pre-commit хук | Скрипт, автоматически запускаемый Git перед коммитом. |
| SemVer | Semantic Versioning — схема нумерации версий MAJOR.MINOR.PATCH. |
